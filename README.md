# Roadwave — Android downloads

Proximity voice chat for drivers.

## 📲 Get the newest build

**[Download the latest APK →](https://github.com/Elekid123/roadwave-releases/releases/latest)**

Tap the `.apk` file under **Assets** on that page.

## First install

1. Download the `.apk` on your Android phone.
2. Open it. Android will ask you to allow installs from your browser —
   allow it (Settings → *Install unknown apps*). This prompt only appears
   the first time.
3. Done. Open Roadwave.

## Updating

Just download the newest APK from the same link and open it — it installs
over your existing app and keeps your settings. No need to uninstall.

---

Every build here is produced automatically by CI from the Roadwave source
repository after its full test and safety gate passes. iOS testers: Roadwave
ships through TestFlight instead — ask for an invite.
